# 📚 Aulão VueJS – Cod3r Cursos

Este repositório contém o código desenvolvido durante o **aulão gratuito de Vue.js** promovido pela [Cod3r Cursos](https://www.cod3r.com.br), ministrado pela professora **Letícia Pegoraro Garcez**.

📺 **Link da aula no YouTube**:  
[![Aulão VueJS - Cod3r](https://img.youtube.com/vi/AdApfFxO3Gs/0.jpg)](https://www.youtube.com/watch?v=AdApfFxO3Gs)

> 🎯 Objetivo: Introduzir os principais conceitos do framework Vue.js na prática, criando uma aplicação simples e funcional.

---

## 🛠️ Tecnologias Utilizadas

- [Vue.js 2.x](https://v2.vuejs.org/)
- HTML5
- CSS3
- JavaScript ES6+
